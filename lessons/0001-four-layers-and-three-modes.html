Four Layers, Three Modes

Kitchen in one lesson — storage, sync, work, collaboration.

Kitchen is not "git in the cloud." It unifies four layers that today are separate tools:

LayerKitchenYou feel
StorageFiles + Versions as rowsHistory without commits
SyncWebSocket pushSave → peers update
WorkMirror at $HOME/ProjectsYour normal editor
CollaborationThree modes (below)Solo, fork, or pair

Three modes of work

Mode 1 — Solo live sync. You save. versions.insert. Other devices update.

Mode 2 — Async concurrent. Two saves → two heads → Pierre Merge.

Mode 3 — Live collab. Pair session → ops → checkpoint → one version.

Live sync (seconds, durable) ≠ live collab (sub-second ops, checkpoint to persist). Voice stays on Discord — Kitchen syncs bytes only.
