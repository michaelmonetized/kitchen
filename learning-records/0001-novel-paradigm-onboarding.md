# Novel paradigm onboarding layer added

Kitchen's model spans storage, sync, work, and collaboration — easy to confuse with git, Drive, or Live Share. Added `docs/the-kitchen-way.md` as the hub, `three-modes-of-work.md`, `storage-and-sync.md`, solo workday walkthrough, and quick reference so new users learn the **whole stack** before entity details.

**Implications:** Future lessons should route through The Kitchen Way. Git comparison is for refugees, not first-time readers.
