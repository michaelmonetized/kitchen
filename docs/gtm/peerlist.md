## Project name

Kitchen

## Headline

Cloud project store · live sync · no git

## Description

Kitchen rethinks where code lives.

**Before:** editor → disk → git → remote. Async by default.  
**After:** cloud Sync Store → WebSocket fan-out → `$HOME/Projects` mirror → your editor.

Every save is versioned. Teammates see changes in seconds. Pair across nvim and VS Code without a browser. Merge concurrent edits by picking lines — not `<<<<<<<`.

Four layers, one model:

1. **Storage** — files as DB rows
2. **Sync** — live WebSockets
3. **Work** — editor-agnostic mirror
4. **Collaboration** — solo · fork · pair

**Role:** Founder / builder  
**Stack:** Next.js, Convex, Clerk, TypeScript  
**Link:** https://kitchen-gilt-nine.vercel.app

Kitchen is a working codename.
