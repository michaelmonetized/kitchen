## Name

Kitchen

## Tagline (≤80 chars)

Live-sync code storage. Cloud truth, disk mirror, no git.

## Description (short)

Files are database rows. Saves append versions. WebSockets sync to every machine in seconds. Your editor reads `$HOME/Projects` — nvim, VS Code, Zed, anything.

Fork and merge by line-pick when edits diverge. Pair across editors via Collab agent.

**Web beta:** https://kitchen-gilt-nine.vercel.app

## Description (one paragraph)

Most devs stack editor, disk, git, and remote hosting. Kitchen collapses storage, sync, work, and collaboration: cloud holds truth, your laptop mirrors it, every save is history, sync is live. Not another IDE — your editors stay. Not git hosting — no push/pull. Try the beta: sign up, create a project, open two tabs, save in one, watch the other update. Kitchen is a codename.
