## Startup name

Kitchen

## One-liner

Your projects live in the cloud. Your editor sees them on disk. There is no git.

## Description (what is it?)

Kitchen is a cloud-native project store for developers who want live sync without git ceremony.

Instead of commit → push → pull, every save appends a version row in a Sync Store and fans out over WebSockets to every machine you're logged into. Your local `$HOME/Projects` folder is a mirror — like Google Drive for code — so you keep VS Code, nvim, Zed, and your existing terminal workflow.

When two people edit the same file without pairing, both versions exist. You merge by picking lines in a visual diff — not conflict markers. For realtime pair programming, a Collab agent per machine bridges your editor to a shared session (voice stays on Discord).

**Web beta is open now** — sign up, create a project, and watch live sync across tabs in under a minute.

## Problem

Developers juggle four systems (editor, disk, git, remote) and accept async collaboration as the default. Live work — pairing, cross-machine sync, fast onboarding — fights the tooling.

## Solution

One model for storage, sync, work, and collaboration. Cloud truth, disk mirror, insert-only versions, human merge when edits diverge. Teams get granular ACL — org roles, per-project assignment, property-based grants on files that inherit down the tree.
